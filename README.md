## 📌 How I Approach Projects

1. **Understand the question** — define the business problem and target metric.
2. **Inspect the data** — review schema, data quality, missing values, and possible bias.
3. **Analyze and build** — write SQL/Python workflows, create visualizations, or train suitable baseline models.
4. **Validate the output** — check calculations, use appropriate evaluation methods, and look for leakage.
5. **Communicate clearly** — document insights, assumptions, limitations, and reproducible steps.
